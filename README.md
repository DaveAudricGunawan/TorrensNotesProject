# Torrens Notes

## About the Project

Torrens Notes is a simple web-based note-taking application inspired by Google Keep. It allows users to create, organise and manage their notes through a clean and easy-to-use interface.

## Features

- Create new notes.
- Edit existing notes.
- Delete unwanted notes.
- Pin important notes.
- Archive and restore notes.
- Search notes by title or content.
- Sort notes by newest, oldest or alphabetical order.
- Choose different colours for notes.
- Save notes using browser Local Storage.
- Access a built-in Help Guide.

## Technologies Used

- **HTML:** Structures the website and its content.
- **CSS:** Controls the layout, colours and overall appearance.
- **JavaScript:** Handles the interactive features and note management.
- **Local Storage:** Saves notes in the browser so they remain available after refreshing the page.

## How to Run

1. Download or open the Torrens Notes project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a web browser, or use the VS Code Live Server extension.
4. Start creating and managing notes.

## Limitations

Torrens Notes currently stores notes locally in the user's browser. It does not support online accounts, cloud synchronisation or sharing notes between devices.

## Purpose

This project demonstrates how HTML, CSS and JavaScript can be used to develop an interactive web application that focuses on usability, accessibility and simple note management.
